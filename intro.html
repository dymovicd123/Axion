Introduction to limits

What is a limit?

Imagine moving along a graph toward a certain point. You can get closer and closer without actually reaching it. A limit describes the value the function is approaching as you do that.

Take the function f(x) = x². If x is close to 2, then x² is close to 4:

1.9² = 3.61; 1.99² = 3.9601; 2.01² = 4.0401

As x gets closer to 2, the results get closer to 4. We write this as:

lim (x → 2) x² = 4

Approaching from both sides

We can move toward 2 from smaller values, like 1.9 and 1.99. This is approaching from the left. Or we can start with larger values, like 2.1 and 2.01, and approach from the right.

For a two-sided limit to exist, the function must approach the same value from both directions. With x², both sides approach 4, so the limit is 4.

The limit is not always f(2)

Here's something important: a limit asks what happens near a point, not necessarily at the point. Even if a function has a hole in its graph at x = 2, it can still approach 4 on both sides.

For example, imagine the graph follows y = x² everywhere except x = 2, where its value is changed to 10. The value at that exact point is now 10, but the limit is still 4.

This is why limits are useful when we study gaps in graphs and, later, continuity and derivatives.
