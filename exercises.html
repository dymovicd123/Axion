Calculating limits / Exercises

Limit exercises

Try solving each limit on paper. Open the answer when you're ready.

1. Direct substitution

lim (x → 2) (x² + 3)

Show answer and explanation

Answer: 7. Substitute x = 2: 2² + 3 = 7.

2. A fraction

lim (x → 3) (x² − 9) / (x − 3)

Show answer and explanation

Answer: 6. Factor the numerator: (x − 3)(x + 3). Cancel (x − 3) for x ≠ 3, then use x + 3 → 6.

3. Another fraction

lim (x → 1) (x² − 1) / (x − 1)

Show answer and explanation

Answer: 2. Factor x² − 1 as (x − 1)(x + 1). For x ≠ 1 the expression equals x + 1, which approaches 2.

4. A square root

lim (x → 4) √(x + 5)

Show answer and explanation

Answer: 3. The square root is continuous here, so substitute x = 4: √9 = 3.
