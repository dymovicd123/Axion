Final assessment

Demonstrate what you have learned across the whole course. This assessment has ten independent problems.

Before starting: Complete the five lessons. Previous lesson.

Writing solution sets

Use parentheses for excluded endpoints and square brackets for included endpoints: (−2, 3) and [−2, 3]. Write inf or ∞ for infinity (always use a parenthesis). Join separate intervals with U. For a single point write {2}; for no solution write empty; for all real numbers write all. Use sqrt(3) for √3.

Independent work

Final assessment

Complete all ten questions independently. You may submit again after reviewing your results. The course is complete when all five lessons and this assessment are passed.

1. Vertex

Find the vertex of 2x² + 8x + 11.

Enter the two coordinates separately; write the y-intercept as a height if requested.

2. Range

Find the range of y = −2(x − 1)² + 5. Enter the interval of y-values.

Answer format: intervals such as (-inf, -2) U [5, inf), a single point {3}, all, or empty. Use sqrt(2) for an exact square root. These are notation examples, not answers.

3. Complete the square

Rewrite x² + 7x + 10 in the form (x − h)² + k.

Enter the two coordinates separately; write the y-intercept as a height if requested.

4. Factorisation

Factor x² − x − 12 into linear factors.

Enter an expression in x, without an equals sign. Use the exponent button for powers and parentheses for grouping.

5. Irrational roots

Solve x² − 4x + 1 = 0. Give both exact roots.

Enter one root per box, in either order. Use the √ button to enter an exact square root. Do not enter ± in a single box.

6. Repeated root

Find m such that x² + 6x + m = 0 has exactly one distinct real root.

7. Strict inequality

Solve x² − 4x − 5 > 0.

Answer format: intervals such as (-inf, -2) U [5, inf), a single point {3}, all, or empty. Use sqrt(2) for an exact square root. These are notation examples, not answers.

8. Non-negative square

Solve (x + 3)² ≥ 0.

Answer format: intervals such as (-inf, -2) U [5, inf), a single point {3}, all, or empty. Use sqrt(2) for an exact square root. These are notation examples, not answers.

9. Optimisation

A rectangle has perimeter 28 m. Find the width that gives the maximum possible area, and calculate that maximum area.

10. Model constraint

The height of an object is h(t) = −t² + 8t for 0 ≤ t ≤ 8. Find the times at which h(t) ≥ 12.

Answer format: intervals such as (-inf, -2) U [5, inf), a single point {3}, all, or empty. Use sqrt(2) for an exact square root. These are notation examples, not answers.
