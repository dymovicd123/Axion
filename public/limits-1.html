Understanding limits

Learn to distinguish the value of a function from the value it approaches, and use measurements to make and test a conjecture.

1. What does approaching mean?

Imagine a car travelling towards a marker at x = 2. Its position can be 1.9, 1.99, 1.999, or 2.001. All these numbers can be close to 2, even though none equals 2. A limit describes the output as the input approaches a particular number, not just the output at that number.

limx→a f(x) = L

Read this as “the limit of f(x) as x approaches a is L”. The letter a is an input; L is an output. If we can force the output as close to L as we want by taking x sufficiently close to a (without x = a), then L is the limit.

Worked example

For f(x) = 2x + 1, values near x = 3 give outputs near 7. For x = 2.99 the output is 6.98; for x = 3.01 it is 7.02. The gap from 7 is exactly twice the gap from 3.

limx→3 (2x + 1) = 7

From an input to a limit

A function takes an input x and gives an output f(x). For a limit, imagine moving the input toward a fixed target a. We are interested in what happens to the output during that movement. We do not need to put x = a into the formula.

For f(x) = 2x + 1, the following table makes the distinction visible. Every row is an ordinary function calculation, such as f(2.9) = 2 · 2.9 + 1 = 6.8.

Both columns approach 7. Here we can even explain why: f(x) − 7 = 2(x − 3), so making x one hundred times closer to 3 makes f(x) one hundred times closer to 7. A table suggests the answer; this algebra explains why it works for all nearby inputs.

For polynomials, including straight lines and quadratics, substitution gives the limit at every real input. For example, limx→2(x² + 1) = 2² + 1 = 5. Later we will see when substitution fails.

2. Experiment: investigate a hidden function

A table is useful when a formula is not available. But a single value cannot tell us a limit. Measure on both sides of the target, then repeat with smaller distances. Look for a stable trend rather than simply picking the last reading.

How to investigate a function

Suppose a machine returns 3.8 at x = 0.9 and 4.2 at x = 1.1. At x = 0.99 and 1.01 it returns 3.98 and 4.02. As both inputs get closer to 1, their outputs get closer to 4. We predict a limit of 4, even if the machine returns something entirely different at x = 1.

3. A hole is not the same as a missing limit

A filled dot represents the function value. An open dot represents an excluded point. The nearby graph can still approach an open dot. It is possible to have a limit even when the function is undefined at the target, or when its assigned value is different.

Worked example

For (x² − 1)/(x − 1), the denominator is zero at x = 1. For all other inputs, the expression simplifies to x + 1. The graph approaches 2, although f(1) is undefined. Cancelling the factor does not restore the missing point.

Why the missing point does not change the limit

Factor the numerator using a difference of squares:

(x² − 1)/(x − 1) = (x − 1)(x + 1)/(x − 1)
= x + 1   for x ≠ 1

At x = 0.99 or 1.01 the original expression and x + 1 give identical outputs. At x = 1 the original expression is 0/0, which is undefined. The simplified expression is therefore useful near 1, but it is not permission to divide by zero at 1 itself.

Changing only f(1), for example by setting it to 10, would not alter any nearby value. The limit would still be 2. In contrast, changing the whole branch on one side can change the limit. That distinction is the subject of the next lesson.

4. Experiment: control the accuracy

A limit is stronger than “it looks close”. For f(x) = x² near x = 2, we want the output within 0.2 of 4. Choosing an input interval (2 − δ, 2 + δ) restricts every input, not just selected samples. On this positive interval x² is increasing, so the two endpoints determine the largest errors.

3.8 < x² < 4.2

Try a radius δ and inspect the entire highlighted input interval. The goal is to keep it inside the output band, with a useful radius of at least 0.03. This is an informal introduction to the precision idea behind limits, not a requirement to memorise the formal epsilon–delta definition.

What does “close enough” mean?

Suppose a sensor should report 4 with an error of less than 0.2. An acceptable reading must lie between 3.8 and 4.2, not merely be close to the target on a drawing. The absolute value |f(x) − 4| is the distance of the reading from 4.

The input radius δ (delta) describes how far x may be from 2. For example, δ = 0.02 means 1.98 < x < 2.02. The inequality |x − 2| < δ describes exactly that interval.

Example with a straight line

For f(x) = 2x, the target output at x = 3 is 6. We want an error below 0.1.

|2x − 6| = 2|x − 3| < 0.1
|x − 3| < 0.05

Choosing δ = 0.05 guarantees the desired accuracy for every input in the open interval. The endpoints themselves are excluded. For a quadratic, we must examine both ends of the interval instead of simply dividing by a constant.

4. Set a measurement tolerance

Choose a radius δ of at least 0.03 and at most 0.1. Every input satisfying |x − 2| < δ must have an output x² strictly between 3.8 and 4.2.

How to answer: Type a radius δ between 0.03 and 0.1. The graph shows the input interval and allowed output band. Inspect the endpoint readings and adjust the radius until all requirements are satisfied. Then check your choice.
