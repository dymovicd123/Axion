Lesson 5

Applications

Build quadratic models, interpret their domains, solve optimisation problems and design your own trajectory.

Before starting: You should know how to find vertices and solve quadratic inequalities. Previous lesson.

1. Translate a situation into a function

We have used quadratic functions to describe a shape, find roots and compare values. In applications, the hard part is often choosing the variable and building the function before doing any algebra.

Suppose we have 40 m of fencing and want to enclose a rectangle. Let x be its width. Because the perimeter is twice the sum of the sides, the length must be 20 − x. The area is the product of the two lengths.

2x + 2l = 40
l = 20 − x
A(x) = x(20 − x)

The physical domain is 0 < x < 20. The formula is defined for all real x, but a negative width or length is not a physical rectangle. Always distinguish a mathematical domain from the domain of a model.

1. Write an area model

Now suppose the perimeter is 50 m. Enter the area function for width x, in standard form or factored form.

How to answer: Here x is the width in metres. Enter A(x) as an expression in x only, without A(x) =.

2. Find a maximum or minimum

For a quadratic function with a negative leading coefficient, its vertex is the highest point. If the vertex lies inside the physical domain, it gives the maximum. This can be found without calculus.

Example: fixed perimeter of 32 m

A(x) = x(16 − x)
= −x² + 16x
= −(x − 8)² + 64

Since (x − 8)² ≥ 0, subtracting it cannot increase 64. Therefore A(x) ≤ 64, with equality only when x = 8. The optimal rectangle is a square with area 64 m².

For a restricted interval, check whether the vertex is allowed. If it is not, compare the values at the permitted endpoints. An open endpoint may prevent the maximum from being attained.

2. Maximise the area

A rectangle has perimeter 24 m. Find the width and maximum area.

How to answer: Give the width in metres and the area in square metres. Enter numbers without units.

3. Height as a function of time

Near Earth, under constant downward acceleration and ignoring air resistance, the height of a thrown object is h(t) = h₀ + v₀t − ½gt². Here t is time, h₀ the starting height and v₀ the initial vertical speed. The negative quadratic term describes gravity. For simple exercises we use g = 10 m/s².

Example: h(t) = −5t² + 10t + 15

h(t) = −5(t − 1)² + 20

The highest point is 20 m at t = 1 s. To find when it lands, solve h(t) = 0: −5(t − 3)(t + 1) = 0. The roots are 3 and −1. Time begins at zero, so the landing time is 3 s. The negative root is a mathematical solution, not an event during this flight.

3. Find the highest point

For h(t) = −5t² + 20t + 3, find the time and height of the maximum.

How to answer: Enter the time and corresponding height separately, without units.

4. Find when a condition is satisfied

Not every application asks for the maximum. We may need to know how long a quantity remains above a minimum value, or which inputs stay below a safety limit. This leads to a quadratic inequality rather than an equation.

Example: at least 15 m above the ground

For h(t) = −5t² + 10t + 15, solve h(t) ≥ 15.

−5t² + 10t ≥ 0
−5t(t − 2) ≥ 0

The downward parabola is non-negative on [0, 2]. Both endpoints are included because “at least” means greater than or equal to. Intersect with the flight domain [0, 3]; the result is still [0, 2].

4. Find the time interval

For h(t) = −5t² + 20t + 3, determine when h(t) ≥ 18 during the flight. Give the interval of time in seconds.

How to answer: Give the full set of times during the flight. Use interval notation, including the endpoints where appropriate.
Interval notation help

Answer format: intervals such as (-inf, -2) U [5, inf), a single point {3}, all, or empty. Use sqrt(2) for an exact square root. These are notation examples, not answers.

5. Design a basketball trajectory

In this investigation, x is horizontal distance in metres and y is height in metres. Instead of being given a quadratic, you will design one. An idealised throw has the form y = ax² + bx + c with a < 0. Every condition below must hold for the same function.

Design requirements

  • The ball starts at (0, 2) and passes through the hoop at (8, 3).
  • At x = 4, it must be at least 4.5 m high to clear the obstacle.
  • The maximum height between x = 0 and x = 8 must not exceed 6 m.
  • The curve must be descending when it reaches the hoop.

Use substitution to connect the coefficients to the two fixed points. Then use the vertex formula to calculate the peak and compare the midpoint with the obstacle. More than one trajectory satisfies the brief. Try different coefficients; the preview shows what your model does, not the answer you should enter.

A downward parabola is descending to the right of its vertex. This gives a way to check the last requirement without knowing derivatives.

5. Design a successful throw

Create one quadratic trajectory that satisfies all five design requirements above.

How to answer: Enter a, b and c for y = ax² + bx + c. The preview updates as you type. Run simulation to watch the flight; compare the measurements with the five requirements. Edit your coefficients and check the final model.

Hint

Start with c = 2. Substituting the hoop position gives 64a + 8b = 1. There are many possible pairs a and b. Use the vertex and the height at x = 4 to test your choice.

Summary

Define variables and the physical domain, construct the function, solve the mathematical problem, and interpret the result in its original context. The same quadratic may be used to answer questions about a maximum, roots or an interval.
