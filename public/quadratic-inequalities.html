Lesson 4

Quadratic inequalities

Solve quadratic inequalities using graphs, sign analysis and exact intervals. Learn how to handle repeated roots and restrictions.

Before starting: You should be able to solve quadratic equations. Previous lesson.

1. What does an inequality ask?

An equation such as f(x) = 0 asks where a graph crosses or touches the x-axis. An inequality asks for a whole set of inputs: f(x) > 0 means the graph lies above the x-axis, and f(x) < 0 means it lies below. Unlike an equation, the answer is usually an interval rather than one or two numbers.

Consider f(x) = x² − x − 6 = (x + 2)(x − 3). Its roots divide the number line into three intervals. Within each interval the polynomial has a constant sign: it is continuous and cannot change sign without crossing zero.

For example, f(x) < 0 has solution (−2, 3). We do not include the roots, because at those points f(x) = 0, not a negative number.

Writing solution sets

Use parentheses for excluded endpoints and square brackets for included endpoints: (−2, 3) and [−2, 3]. Write inf or ∞ for infinity (always use a parenthesis). Join separate intervals with U. For a single point write {2}; for no solution write empty; for all real numbers write all. Use sqrt(3) for √3.

2. Direction and endpoints

Do not memorise “positive outside” without checking the leading coefficient. If a < 0, the parabola opens downwards. Its sign pattern is reversed: positive between two distinct roots, negative outside.

Example: −x² + 3x + 4 ≥ 0

Factor the expression: −x² + 3x + 4 = −(x + 1)(x − 4). The roots are −1 and 4. At x = 0 the expression is 4, so the middle interval is positive. At the roots it is zero. Because the inequality includes equality, the solution is [−1, 4].

In general, multiplying or dividing an inequality by a negative number reverses its direction. Thus −(x + 1)(x − 4) ≥ 0 becomes (x + 1)(x − 4) ≤ 0. The roots do not change, but the required sign does.

3. Put zero on one side

When both sides contain variables, first subtract the right-hand side. We need to compare a single expression with zero before using its roots and sign. Adding or subtracting the same expression on both sides preserves the inequality. Dividing by an expression with unknown sign does not.

Example: x² + 2x ≤ x + 12

x² + x − 12 ≤ 0
(x + 4)(x − 3) ≤ 0

The roots are −4 and 3. The leading coefficient is positive, so the expression is negative inside the interval and zero at both ends. The solution is [−4, 3].

If factorisation is difficult, use the quadratic formula from the previous lesson. Irrational endpoints are still exact numbers. For x² < 5, the solution is (−√5, √5), not merely an interval rounded to one decimal place.

4. One repeated root or no real roots

When D = 0, a quadratic is a constant multiple of a perfect square. It touches the x-axis but does not cross it. When D < 0, it never meets the x-axis, so its sign is the same for every real number.

Example: (x + 1)² > 0

A square is zero only at x = −1 and positive everywhere else. The answer is (−∞, −1) ∪ (−1, ∞). If the sign were ≥ instead, every real number would be included.

Example: x² + 2x + 3 < 0

(x + 1)² + 2 < 0

The left side is at least 2, so no real number satisfies the inequality. The solution set is empty.

5. More than one condition

Sometimes a mathematical model or a system of inequalities restricts the allowed values. If both conditions must hold, take their intersection: keep only values that belong to both sets.

Example: x² − 9 ≤ 0 and x > 1

The quadratic inequality gives [−3, 3]. The second condition gives (1, ∞). Their overlap is (1, 3]. Notice that the endpoint 1 is excluded by the second condition, even though it satisfies the first.

Summary

Move everything to one side, find real roots, test signs, choose the intervals and decide which endpoints are included. When a condition restricts the domain, intersect the solution with that domain.
