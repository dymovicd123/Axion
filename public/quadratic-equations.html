Lesson 3

Quadratic equations

Learn to solve quadratic equations by factoring, completing the square and using the quadratic formula. Determine the number of real roots before solving.

Before starting: You should know how to complete the square. Previous lesson.

1. Roots and factorisation

A quadratic function describes a whole curve. A quadratic equation asks for particular inputs that satisfy an equality. To solve ax² + bx + c = 0 is to find where the graph crosses or touches the x-axis. These inputs are called roots or solutions.

Before solving, put all terms on one side. For example, x² + 2x = 8 becomes x² + 2x − 8 = 0. One useful method is to factor the expression.

Zero-product property: if AB = 0, then A = 0 or B = 0. It does not apply when AB equals a non-zero number.

Example: x² + 2x − 8 = 0

Look for two numbers whose sum is 2 and product is −8: 4 and −2. Then

(x + 4)(x − 2) = 0
x + 4 = 0 or x − 2 = 0
x = −4 or x = 2

Check either value in the original equation. For x = 2, 4 + 4 − 8 = 0.

For a leading coefficient other than 1, factoring can require an extra step. For example, 2x² + 7x + 3 = (2x + 1)(x + 3). Expanding verifies the factors; the roots are −1/2 and −3. Not every quadratic factors into integer coefficients.

1. Factor and find roots

Factor x² + 3x − 10 and find both roots. Enter your own product of linear factors, such as (x+1)(x−4). Roots may be in either order.

How to answer: Enter a product of two linear factors, then one root in each of the two boxes. The order of the roots does not matter.

2. Equations with a missing term

When c = 0, both terms contain x. Factor x out instead of dividing by it. Dividing by x assumes x ≠ 0, which can discard an actual solution.

Example: 2x² − 10x = 0

2x(x − 5) = 0
x = 0 or x = 5

Both values satisfy the equation. Dividing by x at the beginning would have left only x = 5.

When b = 0, isolate x². For instance, 3x² − 12 = 0 gives x² = 4, so x = ±2. If x² = 0, the only root is 0. If x² is negative, there is no real solution because the square of a real number is non-negative.

2. Solve a missing-term equation

Solve 3x² − 12x = 0. Give both roots.

How to answer: Enter the two roots separately, in either order.

3. Solving by completing the square

Some equations do not factor neatly. Completing the square still works, because it reduces the problem to a squared expression equalling a constant.

Example: x² − 6x + 2 = 0

(x − 3)² − 7 = 0
(x − 3)² = 7
x − 3 = ±√7
x = 3 ± √7

Taking the square root introduces two signs. Both positive and negative numbers can have the same square. Keep the roots exact rather than rounding early.

For 2x² + 8x + 2 = 0, divide all terms by 2 first. Then x² + 4x + 1 = 0 becomes (x + 2)² = 3 and the roots are −2 ± √3.

3. Solve using the square

Solve x² + 4x − 3 = 0. Enter the two exact roots separately. Use the square-root button in the answer field.

How to answer: Use the √ button to enter an exact square root. Write one root per box, not ± in a single box.

4. The quadratic formula

The quadratic formula is not an unrelated rule to memorise. It follows from completing the square in the general equation. For a ≠ 0, divide by a and move the constant to the right.

x² + (b/a)x = −c/a
(x + b/(2a))² = b²/(4a²) − c/a
(2ax + b)² = b² − 4ac

Multiplying by 4a² produces the last line. If the right-hand side is non-negative, take both square roots and solve for x.

x = −b ± √(b² − 4ac)2a

Write D = b² − 4ac. This is the discriminant.

Example: 3x² − 5x − 2 = 0

Identify a = 3, b = −5, c = −2. Keep the negative signs when substituting.

D = (−5)² − 4·3·(−2) = 49
x = (5 ± 7)/6
x = 2 or x = −1/3

Remember that 2a divides the entire numerator, not just the square root. Substituting each root gives zero.

4. Use the quadratic formula

Solve 2x² + 5x − 3 = 0 using the quadratic formula. Give the discriminant and both roots.

How to answer: Enter the numerical discriminant D and both roots separately.

5. The discriminant and the graph

From (2ax + b)² = D we can tell how many real roots exist without calculating them. When D > 0 there are two possible signs of √D. When D = 0 both signs give the same repeated root. When D < 0 the equality cannot hold for real x.

Example: find a parameter

For what value of m does x² + 8x + m = 0 have exactly one real root? We need D = 0, so 64 − 4m = 0. Therefore m = 16. The equation becomes (x + 4)² = 0 and its repeated root is −4.

5. Analyse the discriminant

For x² − 6x + 11 = 0, find D and the number of distinct real roots. Then find m so x² − 6x + m = 0 has one repeated root.

How to answer: The first two fields refer to the given equation. The last asks for the new constant m in the second equation.

Choosing a method

First put the equation equal to zero. If a term is missing, isolate the square or factor out x. If integer factors are easy to find, use factorisation. Otherwise completing the square or the quadratic formula works for any quadratic. Use the discriminant to decide how many real roots to expect, and check your solutions.
