One-sided limits and continuity

Compare the behaviour on either side of a point, classify discontinuities, and construct functions satisfying your own conditions.

1. Two directions, two limits

An input approaching a from the left is always smaller than a; from the right it is always larger. The notation x→a⁻ and x→a⁺ records this distinction. It does not mean the outputs must be smaller or larger than the limit.

limx→a⁻ f(x) = L₋    limx→a⁺ f(x) = L₊

A finite two-sided limit exists exactly when both finite one-sided limits exist and are equal. If they differ, moving closer to a does not remove the disagreement.

Worked example

For f(x) = 2x + 1 when x < 1 and f(x) = x − 1 when x > 1, the left limit at 1 is 3 and the right limit is 0. The two-sided limit does not exist (DNE).

For instance, x = 1.99 approaches 2 from the left, whereas x = 2.01 approaches 2 from the right. The superscript minus or plus belongs to the direction of x, not the sign of f(x).

Reading a piecewise rule

Suppose f(x) = x + 3 for x < 2 and f(x) = 2x for x ≥ 2. At x = 1.99 use only the first rule, giving 4.99. At x = 2.01 use only the second rule, giving 4.02.

limx→2⁻ f(x) = 5
limx→2⁺ f(x) = 4

There is no number approached from both sides. Although f(2) = 4, the two-sided limit does not exist. DNE stands for “does not exist”; it is not zero.

1. Compare two one-sided limits

Let f(x) = 2x + 3 for x < 2 and f(x) = 8 − x for x > 2. Find the left-hand and right-hand limits as x approaches 2. Does the two-sided limit exist?

How to answer: At x = 2, give the left-hand limit, the right-hand limit, and select whether a common two-sided limit exists.

2. When is a function continuous?

At a particular input a, continuity requires three facts: f(a) is defined; the finite two-sided limit exists; and this limit equals f(a). Each condition matters. A removable discontinuity occurs when the finite limit exists but the point is missing or incorrectly assigned.

Worked example

Let f(x) = (x² − 4)/(x − 2) for x ≠ 2 and f(2) = k. Since the nearby expression equals x + 2, the limit is 4. The only choice that makes f continuous at 2 is k = 4.

Three checks, in order

  1. Find the function value at the target. If it is missing, the function is not continuous there.
  2. Find the left and right limits. They must approach the same finite number.
  3. Compare the common limit with the assigned value. Only equality makes the function continuous at that point.

For a jump, changing just the filled dot cannot make the branches meet. For a removable discontinuity, the branches already meet at a common height; adding or moving one dot is enough. An infinite discontinuity is different again: a branch grows without bound near the point. We will investigate that case in lesson 4.

2. Fill a missing point

Define f(x) = (x² − 16)/(x − 4) for x ≠ 4 and f(4) = k. Find k so the function is continuous at x = 4.

How to answer: Give the numerical value assigned to f(4) that makes the function continuous at x = 4.

3. Find a missing parameter

Piecewise functions use different rules on different intervals. If each branch is a polynomial, its one-sided limit at the boundary is obtained by substitution into that branch. To join the branches continuously, equate these limits and ensure the assigned point has that same value.

Worked example

f(x) = { 3x + k, x < 2; x², x ≥ 2 }

At x = 2, the left limit is 6 + k and the right limit and function value are 4. Therefore 6 + k = 4, so k = −2. The slopes need not match; continuity only requires the heights to join.

Think of k as a number we have not chosen yet. We are not solving f(x) = 0. Instead, we are trying to make the two formulas give the same height at the boundary. The boundary condition (such as x ≥ 2) tells us which branch supplies the actual value.

Example with k multiplying x

Let f(x) = kx + 1 for x < 2 and f(x) = x + 5 for x ≥ 2. The left branch approaches 2k + 1; the right branch approaches 7 and f(2) is also 7.

2k + 1 = 7
2k = 6
k = 3

Check: the two branch heights at 2 are both 7. The function is continuous there, even though the two slopes are different.

3. Find the joining parameter

f(x) = kx − 1 for x < 3, and f(x) = x + 2 for x ≥ 3. Find k for continuity at 3.

How to answer: Enter k, not the height of the joined graph.

4. Construction: build a counterexample

A common mistake is to think that a defined value f(a) guarantees a limit at a. To disprove this statement, construct a function with a defined value at the target but different left and right limits. You can choose independent slopes for the two straight-line branches; the intercepts determine where the branches meet the target.

The graph below is your own piecewise function, not a preset. The function value at x = 1 is independent of both branches. Draw each branch by choosing two points on the grid, or enter coefficients directly. Then assign the isolated point and submit your construction.

Writing two straight-line rules

A straight line y = mx + b has slope m (the change in y for a unit change in x) and intercept b (the height at x = 0). We can use it on only one side of a boundary. For a boundary at x = 0, the rule 2x + 3 on the left approaches 3 and the rule −x + 1 on the right approaches 1. We could assign f(0) = 5 independently. The branches are not continuous, but the function is defined at the boundary.

In the exercise the boundary is x = 1. Each branch has its own m and b, and both slopes must be nonzero. You can create many different valid lines. A hollow circle shows the height a branch approaches; a solid circle shows the value assigned at the boundary.
