Lesson 1

Quadratic functions

Learn to recognise a quadratic function, understand the shape of its graph, and find or construct a parabola from its defining properties.

Before starting: You should know how to substitute numbers into expressions, expand brackets and plot points on a coordinate plane.

1. What makes a function quadratic?

Imagine a square garden with side length x metres. Its area is x² square metres. If you double the side length, the area does not merely double: it becomes four times as large. This is a simple example of a quadratic relationship.

A linear function changes by the same amount whenever x increases by 1. A quadratic function generally does not. The rate at which the output changes itself changes.

x01234
Linear: 2x02468
Change—+2+2+2+2
Quadratic: x²014916
Change—+1+3+5+7

Notice that the second row of changes for x² increases by 2 each time. For equally spaced inputs, a quadratic has constant second differences. This is another way to recognise a quadratic pattern.

Definition
f(x) = ax² + bx + c,   a ≠ 0

The numbers a, b and c are constants. The condition a ≠ 0 matters: if a is zero, the squared term disappears and the function is no longer quadratic.

For example, f(x) = −2x² + 3 is quadratic, even though the x term is missing. Here a = −2, b = 0 and c = 3. An expression does not have to be written in standard form to be quadratic: expand and simplify it first.

Example

Is (x + 1)² + 2x quadratic?

(x + 1)² + 2x
= x² + 2x + 1 + 2x
= x² + 4x + 1

Yes. The highest remaining power is 2, with a non-zero coefficient.

2. Reading a parabola

The graph of every quadratic function is called a parabola. Start with the simplest one: y = x². Squaring −2 and 2 gives the same result, 4. Likewise, −1 and 1 both give 1. Points at opposite distances from 0 lie at the same height, so the graph is symmetric about the vertical line x = 0.

In the model above, the sign of a determines the direction in which the parabola opens. When a is positive, the graph opens upwards and has a minimum. When a is negative, it opens downwards and has a maximum. A larger |a| makes the graph narrower: for the same distance from the axis, the vertical change is greater.

The vertex is the turning point. The axis of symmetry is the vertical line through that point. The y-intercept is where the graph crosses the vertical axis, and is found by substituting x = 0. An x-intercept occurs where y = 0. A parabola can have zero, one or two distinct x-intercepts; solving for them is the subject of a later lesson.

3. Vertex form

Suppose the vertex is no longer at the origin. We can write a quadratic so that its vertex is visible directly in the formula.

f(x) = a(x − h)² + k,   a ≠ 0

The vertex is (h, k), the axis of symmetry is x = h, and a determines the opening direction and vertical stretch.

Why? When x = h, the squared part becomes zero. At any other x, (x − h)² is strictly positive. If a > 0, that makes f(x) greater than k; if a < 0, it makes f(x) smaller than k. The turning point must therefore be (h, k).

Moving the graph to the right by 2 replaces x with x − 2. It is easy to make a sign error here: in (x − 2)² the expression is zero at x = 2, not x = −2. Subtracting 3 outside the brackets then moves every point down by 3.

Example: domain, range and intercept

Consider f(x) = −2(x + 1)² + 5. Rewrite x + 1 as x − (−1). The vertex is (−1, 5). Because a = −2, the parabola opens down and has a maximum of 5.

The domain (allowed x-values) is all real numbers. The range (possible outputs) is y ≤ 5. To find the y-intercept, substitute x = 0:

f(0) = −2(0 + 1)² + 5 = 3

So the graph passes through (0, 3).

4. Finding the vertex from standard form

In the standard form f(x) = ax² + bx + c, the vertex is not obvious. We need a method that works without drawing the whole graph. In the next lesson we will learn to convert standard form into vertex form by completing the square. For now, use symmetry.

Let x = h + t and x = h − t be equally far from the axis x = h. Their outputs must be equal. Substitute into the quadratic and subtract:

f(h + t) − f(h − t)
= a[(h + t)² − (h − t)²] + 2bt
= 4aht + 2bt
= 2t(2ah + b)

For any non-zero t, this difference is zero only if 2ah + b = 0. Solving for h gives the x-coordinate of the vertex. Then substitute h into the original function to obtain its y-coordinate.

−b2a = h,   k = f(h)

The x-coordinate is not the minimum or maximum value itself. It tells us where that value occurs.

Example: find the vertex of f(x) = 2x² − 8x + 3

  1. Identify a = 2, b = −8, c = 3.
  2. Calculate h = −(−8)/(2·2) = 2.
  3. Calculate k = f(2) = 2·4 − 8·2 + 3 = −5.
  4. Since a > 0, the vertex (2, −5) is a minimum. The range is y ≥ −5.

The y-intercept is (0, 3). Its reflection across x = 2 is (4, 3), a useful way to check the sketch.

5. Construct a parabola from its properties

Finding features from a formula is one direction of the problem. We can also work backwards. If the vertex (h, k) and one other point (p, q) with p ≠ h are known, the equation q = a(p − h)² + k determines the remaining coefficient.

Example

Find a parabola with a minimum at (1, −2) that passes through (3, 6).

f(x) = a(x − 1)² − 2
6 = a(3 − 1)² − 2
8 = 4a
a = 2

The function is f(x) = 2(x − 1)² − 2. Its coefficient is positive, which agrees with the given minimum. Substituting x = 3 gives 6, so both conditions hold.

What to remember

Standard form gives the coefficients and the y-intercept. Vertex form gives the turning point and its axis directly. The sign of a tells you whether the vertex is a minimum or a maximum. To determine a parabola from its vertex and a second point, substitute the point and solve for a.
