Calculating limits

First, try substitution

For many simple functions, calculating a limit is straightforward: replace x with the number it approaches. This works for polynomials, and it works for fractions when the denominator does not become zero.

For example, when x approaches 3:

lim (x → 3) (x² + 1) = 3² + 1 = 10

There is no problem with putting 3 into this expression, so the answer is 10.

What if substitution gives 0/0?

Sometimes direct substitution gives 0/0. That is not the answer. It means we cannot evaluate the fraction this way, and we should try simplifying it.

Consider this limit:

lim (x → 2) (x² − 4) / (x − 2)

Putting x = 2 gives 0/0. But notice that x² − 4 = (x − 2)(x + 2). We can factor the numerator and cancel the common term:

(x² − 4) / (x − 2) = x + 2,   x ≠ 2

We are allowed to cancel it for values near 2, not at 2 itself. That's enough for a limit. Now we can substitute:

lim (x → 2) (x + 2) = 4

The original fraction is undefined at x = 2, but its limit is 4. This connects directly to what we learned in the introduction.

Which method should I use?

Start with substitution. If you get an ordinary number, you're done. If you get 0/0, look for something you can simplify, such as factoring a polynomial. Then try substitution again.

Not every difficult limit can be solved by factoring, but these two methods are a good starting point.
